# ドット絵キーキャップ

MX互換キースイッチ用のキーキャップに、ドット絵を描いて3Dで仕上がりを確認できるWebツールです。

- 18mm角・1マス2mm・8×8マス（枠の外に2マスまではみ出せます）
- マスをタップして描くだけ。3Dプレビューで仕上がりを確認できます
- 描いた絵は作品ファイル（.json）で保存・読み込みできます
- 公開版には3Dプリント用データ（3MF）の保存はありません

**使う:** https://hachi-bit.github.io/pixel-keycap-tool/
